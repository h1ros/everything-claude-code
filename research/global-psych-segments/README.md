# 世界各国 国民心理セグメンテーション・レポート

世界の主要大陸から各5カ国を抽出し、各国民の心理状況を **5〜10個のセグメント** に分け、割合と多次元プロフィール（心情・家族・経済・社会・教育・食・政治・対国家／対外感情・関心事・AI受容など）をソース付きでまとめたコレクションです。マルチエージェント（地域担当ペルソナ）による分業で作成しました。

> 作成日: 2026-06-15 / 手法: マルチエージェント分業（大陸ごとに専任アナリスト・ペルソナ）

---

## ⚠️ 方法論と限界（必読）

このレポートで最も重要なのは「数字をどう読むか」です。

1. **「国 × 心理セグメント × 割合」を直接スクレイピングした検証済み統計は実在しません。**
   Reddit / Instagram / X(Twitter) を集計しても、国民全体を代表する心理セグメント比率は得られません（SNS利用者は若年・都市・特定層に偏る＝**サンプリングバイアス**）。

2. 本レポートのセグメントと割合は、以下を組み合わせた **解釈的推定（interpretive segmentation）** です。
   - **一次ソース（実測）**: 学術的・代表性のある世論調査
     - Pew Research Center, World Values Survey, Gallup World Poll
     - Edelman Trust Barometer, Reuters Institute Digital News Report
     - 地域別: Eurobarometer（欧州）, Afrobarometer（アフリカ）, Latinobarómetro（中南米）, Lowy Institute Poll（豪・太平洋）
     - 各国の国内世論調査機関 / 統計局
   - **SNS言説分析**: 各国のSNS/フォーラム上で観測される語り口・関心・対立軸の定性的傾向（および公開されている感情分析の論文・記事）
   - **アナリストによる統合**: 上記を束ねてペルソナ的セグメントに再構成

3. 各セグメントの割合には **「実測ベース／解釈的推定」の別を明示** しています。割合は概念的な規模感であり、誤差は小さくありません。±数〜十数ポイントの幅で読んでください。

4. **使ってよい場面 / 使ってはいけない場面**
   - ✅ 仮説出し、ペルソナ設計、地域比較の出発点、議論のたたき台
   - ❌ 政策・投資・学術的主張の根拠となる確定値としての引用

## 各国レポートの共通スキーマ

各セグメントは以下の次元で記述されます。

- セグメント名 / 推定割合（実測 or 推定の別を明示）
- 心情（支配的な感情）
- 家族・生活環境
- 人間関係
- 経済状況
- 社会観
- 教育状況
- 食事事情
- 政治スタンス
- 国家への期待／不満
- 自国と外国への思い
- 最も関心のあること
- AI受容度（高/中/低 ＋ 具体）
